# Phase 3 — authority, effects, privacy, security and safety

This candidate constitution preserves the complete governed-effect chain:

```text
authority source → delegation → policy decision → action authorization
→ effect intent → attempt → observation → receipt → accepted outcome
```

It defines 16 authority coordinates, 10 trust coordinates, 16 effect coordinates, six boundary
kinds, and separate privacy, security and safety profiles. It prohibits universal authority,
policy-result, effect, security-context, privacy-flag, risk-score and safety-status facades.

Eight bounded claims use XACML, NIST ABAC, ODRL, HTTP semantics, OAuth token revocation, the NIST
Privacy Framework, NIST trustworthy-systems engineering and SLSA. The package decides no law,
accepts no risk, qualifies no implementation and closes no canonical exact contract.
