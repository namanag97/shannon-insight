# Phase 4 — representation and evolution

This candidate constitution prevents the compiler from treating schemas, formats, DTOs and
versions as meaning. It decomposes representation into ten layers and makes compatibility a
directional vector over fifteen dimensions and a named consumer/profile.

It is deliberately not a universal schema or migration library. Existing owners remain sovereign;
family reviews bind this constitution by reference and record only applicability and exceptions.
No canonical gap is closed until named owners ratify the constitution and exact source contracts.

Run `python3 build_phase4.py`, then `python3 validate.py`.
