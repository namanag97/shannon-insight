# Compatibility/evolution coordinate ontology

Compatibility is a directional relation over exact source and target editions, consumers/providers,
a declared profile, history, environment and evidence—not a Boolean property or version label.

Fifty bearer archetypes and seventy-two kernels cover semantic/API/schema/wire/ABI/behavior/
operational/risk diffs; compatibility vectors; consumer census; adapters; migration, backfill,
reprocessing and replay; dual/shadow/parallel operation; in-flight work; canary, rollout, rollback and
roll-forward; deprecation, replacement, portability, decommission and evidence renewal. All 674
members route losslessly while every applicability, owner, compatibility and exact-contract decision
remains open.

Run `python3 build_compatibility_evolution_coordinate_ontology.py` and `python3 validate.py`.
