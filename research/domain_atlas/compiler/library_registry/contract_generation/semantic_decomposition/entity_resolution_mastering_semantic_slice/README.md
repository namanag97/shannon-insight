# Entity resolution, master data and reference data semantic slice

This deterministic, evidence-backed and unratified research slice decomposes the open
`formalism.entity_resolution_mastering` frontier cluster. It tests the existing product and library
graph rather than assuming its names are correct.

## Boundary result

The candidate quotient has three independently adoptable products:

```text
source record occurrences
        │ normalize / block / compare / assess / review
        ▼
Entity Resolution
        │ resolution assertions + cluster editions
        ▼
Master Data Governance
        │ master identity + field authority + survivorship + golden projection
        │ may consume independently governed code and concept editions
        ▼
Reference Data Governance
        code systems + reference/value sets + crosswalks + mapping loss
```

- Retain `product.entity_resolution`, but reclassify master identity, source authority,
  survivorship, stewardship and golden-record libraries as capability imports rather than owned
  lifecycle.
- Preserve the completed no-alias replacement of `product.master_reference_data` by the independently
  retained but still unratified `product.master_data_governance` and
  `product.reference_data_governance` boundaries.
- Keep pair assessment, pair decision, cluster edition and master identity distinct.
- Keep master entities distinct from reference values, and concept, code, designation, value-set
  definition, value-set expansion and directional mapping distinct.
- Split the `canonicalization` homonym into byte/document canonicalization, identifier
  normalization, entity representative selection and master golden projection.
