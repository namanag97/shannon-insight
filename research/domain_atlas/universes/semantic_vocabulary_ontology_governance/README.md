# Business Glossary and Ontology/Knowledge-Model Governance

This universe makes language and formal knowledge compiler-addressable without collapsing text, concepts, taxonomies, axioms, inference, graph constraints or observed truth.

```text
Business Glossary                         Ontology / Knowledge Model
├── concept + designation identity        ├── ontology identity + import closure
├── scoped definition editions            ├── axiom + logic profiles
├── lexical relations + resolution        ├── reasoning + entailment
├── taxonomy / concept schemes            ├── graph-shape validation
└── stewardship lifecycle                 ├── ontology mappings
                                          └── knowledge-graph releases
```

Critical laws:

```text
text != designation != concept != definition
synonym != identity; translation != equivalence
taxonomy broader != OWL subsumption
ontology IRI != version IRI != document location != registry occurrence
annotation != logical axiom != observed fact
profile membership != consistency != entailment != truth
SHACL conformance != ontology consistency != data completeness
canonical RDF digest != semantic equivalence
knowledge-graph assertion != source truth
```

Publication, registration, approval, mapping and graph-release operations emit pure effect intents. Reasoning and shape validation are pure, finite-budget algorithms over exact immutable cuts. Every reference offer remains unqualified, non-portable and non-selectable.
