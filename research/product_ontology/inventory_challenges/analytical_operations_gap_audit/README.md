# Analytical-operations product-inventory gap audit

This is a deterministic, evidence-backed challenge of the current finite 66-candidate global
inventory. It does not add or ratify products. It identifies five boundaries with enough evidence
to require full adjudication:

1. self-service data preparation;
2. annotation and ground-truth operations;
3. document processing and review operations;
4. visual inspection operations; and
5. signal condition monitoring and diagnostics.

The proposed products are defined by user job, semantic ownership, lifecycle, authority, operation,
support and exit—not by AI. Rule-based, statistical, predictive, generative and human methods may
bind through typed method ports. LLMs and agents are optional proposals when declared by intent.
Removing them preserves the deterministic lifecycle, evidence and refusal behavior.

Every proposed boundary includes a deterministic core, explicit collision ruling against existing
products, at least six primary or official sources, a preliminary ten-axis split test, falsifiers,
blocking evidence gaps and a first library-boundary decomposition. Seven additional hypotheses stay
deferred because their sovereign product boundary is not yet proven.

Build and validate:

```text
python3 build_bundle.py
python3 build_bundle.py --check
python3 validate.py
```
