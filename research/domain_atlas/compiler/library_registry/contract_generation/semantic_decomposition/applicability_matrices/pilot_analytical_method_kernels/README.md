# Analytical method-kernel semantic pilot

This pilot replaces lexical-only discovery with structured evidence already present in the
method-kernel source corpus. Every one of the 72 library records is projected across all sixteen
axes. Exact public type names, trait names and operation references are extracted into governed
exact-contract input candidates.

The extraction is not ratification. Source fields can narrow research and populate candidate API
slots, but they cannot decide applicability, semantic completeness, public signatures, law
ownership or implementation conformance. Empty structured evidence is preserved as an evidence
vacancy, not interpreted as inapplicable.

The 325 vacancies are grouped by semantic axis and library role in
`evidence-vacancy-work-packages.jsonl`. Only six axes need this follow-up. Each packet asks one
constitutional research question and requires shared decisions, exceptions, collisions, negative
twins and explicit residual ownership instead of repeating a generic checklist per library.

Run `python3 build_pilot.py`, then `python3 validate.py`.
