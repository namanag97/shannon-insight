# P3E — grain/cardinality evidence campaign

This campaign attacks the largest unresolved family-axis evidence lane without pretending that one
source can define a whole family. It routes one bounded primary-source coordinate claim to each of
the 23 family work packages, covering 638 library occurrences.

Each candidate states what its source can establish, what it cannot establish and a negative twin
that must fail. The result is an evidence seed, not a family default. Member applicability,
exception clusters, semantic ownership, exact contracts, implementation qualification and product
acceptance remain unresolved.

```text
23 primary-source candidates
        |
23 family-axis dockets
        |
638 exact library occurrences remain attributable
        |
owner/applicability review -> exact contract lowering (still fail-closed)
```

Run:

```sh
python3 research/domain_atlas/compiler/library_registry/contract_generation/semantic_decomposition/p3e_grain_cardinality_evidence/build_p3e.py
python3 research/domain_atlas/compiler/library_registry/contract_generation/semantic_decomposition/p3e_grain_cardinality_evidence/validate.py
```
