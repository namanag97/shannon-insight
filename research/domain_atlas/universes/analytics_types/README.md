# Analytical-practice universe

This registry owns **horizontal analytical practices**. It does not own industry questions and it
does not equate analytics with KPIs.

```text
portable analytical practice                 situated vertical analytical case
------------------------------------          ---------------------------------------------
stress testing                               CCR stress/default-path analysis
conformance checking                         anti-money-laundering case-work conformance
survival analysis                            patient time-to-event outcome analysis
bottleneck localization                      port-terminal congestion diagnosis
causal effect estimation                     retail promotion incrementality decision
```

A practice is distinct only when its intent, method/study design, input/output contract,
assumptions, uncertainty, validation or evidence obligations differ materially. A dashboard tile,
metric name, industry noun, vendor feature or arbitrary cross-product of facets is not a practice.

`build_seed.py` emits an intentionally broad **hypothesis queue**. The queue is not an assertion that
every name is a separate type and is not a completeness claim. Split/merge adjudication, exact
definitions, primary evidence, ownership and compiler mappings remain mandatory.

LLM, prompt, RAG, generative and agent-memory semantics are excluded from the core. Classical
statistical, mathematical, operations-research, signal-processing and non-generative data-mining
practices remain in scope because excluding them would make “all analytics” false.
