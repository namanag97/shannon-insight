# Effect-boundary coordinate ontology

This package separates pure results, effect descriptions, proposals, commands, authorized intents,
attempts, provider requests, acceptance, acknowledgements, progress, commits, completion claims,
partial/unknown outcomes, receipts, reconciliation, retries, cancellation, rollback, compensation,
reversal, deletion/erasure and consumer/business acceptance.

Forty-two effect bearers and sixty kernels route all 674 members through exact stage-aware clusters.
All members have an explicit source-level effect-class candidate, but those coarse classes do not
decide operation stages, idempotency, retry, reconciliation, acceptance, ownership or exact
contracts. All 23 family dockets remain decision-open.

Run `python3 build_effect_boundary_coordinate_ontology.py` and `python3 validate.py`.
