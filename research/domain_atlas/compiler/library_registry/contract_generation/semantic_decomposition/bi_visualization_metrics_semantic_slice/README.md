# BI, visualization, semantic-metric and formula semantic slice

This unratified research package decomposes governed analytical meaning and presentation without
turning a formula, metric, query, chart, dashboard, alert or embedded surface into the same owner.

```text
approved business concept + analytical population + grain
                         |
                         +--> measure + dimension + hierarchy
                         |          |
                         |          +--> formula AST + binding + evaluation
                         |          +--> aggregation + summarizability + fanout proof
                         |          +--> unit + time + missingness + uncertainty
                         |                         |
                         |                         +--> metric observation + receipt
                         |
                         +--> semantic query --ACL--> relational query execution
                                                   |
                                                   +--> typed result + evidence
                                                               |
                  presentation definition + data/task abstraction
                                  |
                                  +--> visual encoding + scale + layout
                                  +--> table + pivot + interaction history
                                  +--> dashboard + report + snapshot
                                  +--> alert + subscription + export
                                  +--> embedded/offline runtime
                                  +--> accessibility + localization

metric definition != formula AST != evaluated observation != query result
query result != presentation != report snapshot != alert delivery != business decision/effect
```

The live product graph preserves three distinct products:

```text
semantic metric/formula service
  owns governed definition, binding, evaluation, observations and equivalence evidence
  excludes source truth, glossary approval, physical query execution, presentation and decisions

BI reporting
  owns report/dashboard/view/snapshot/alert/subscription/export lifecycles
  excludes metric meaning, source truth, physical query execution, policy and notification authority

embedded analytics
  owns the host/guest delivery, entitlement-projection and runtime seam
  reuses reporting/metric/query contracts and does not absorb host business logic
```

The package binds the exact 39 unique concrete libraries declared by those products and 31
justified formalism/ACL neighbors. It contains 50 primary or official sources, 65 semantic
modules, 74 non-collapse laws, 158 method types, 24 expert learning profiles, 14 recent non-LLM
innovation records, 70 library bindings, 1,120 unresolved library-axis questions, 12 typed
missing-library candidates and 20 boundary findings.

No source or structural match ratifies an owner, member applicability, coordinate value, exact
contract, provider, implementation or product readiness. Nine libraries still lack complete P5
plus coordinate routes. All compiler bindings therefore remain refused.
