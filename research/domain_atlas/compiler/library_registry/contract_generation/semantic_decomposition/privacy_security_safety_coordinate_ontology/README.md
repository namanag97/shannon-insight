# Privacy/security/safety coordinate ontology

Privacy governs affected people/data, purpose and processing; security governs assets, adversaries,
trust boundaries and controls; safety governs unacceptable losses, hazards, control structures and
safe/degraded states. They interact but are not interchangeable.

Sixty bearers and eighty kernels route all 674 members through exact cross-concern clusters. The 85
lexical candidates and 589 no-signal members remain research-open. Controls, cryptography,
provenance, authentication, deletion requests, alarms and risk scores cannot stand in for scoped
effectiveness, erasure, authorization, safe state or named residual-risk acceptance.

Run `python3 build_privacy_security_safety_coordinate_ontology.py` and `python3 validate.py`.
