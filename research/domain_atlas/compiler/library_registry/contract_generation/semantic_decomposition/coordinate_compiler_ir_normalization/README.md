# Coordinate compiler-IR normalization

The coordinate ontologies evolved in two generations. Seven already expose common required
coordinate fields, total outcomes and compiler refusals; nine preserve equivalent material in
axis-native structures. This package projects all sixteen into one inspectable compiler contract
without rewriting the source ontologies.

Normalization is structural only. Exact coordinate answers, refusal precedence, applicability,
owners, contracts and lowering remain open. The compiler must refuse rather than fill any of those
vacancies with defaults.

Run `python3 build_coordinate_compiler_ir_normalization.py` and `python3 validate.py`.
