# Package manifest

This handoff packages a read-only snapshot of the current product-ontology and semantic research
corpus for independent GPT Pro convergence research.

Included:

- `research/handoffs/gpt-pro-product-ontology-convergence/GPT-PRO-PROMPT.md`
- `research/handoffs/gpt-pro-product-ontology-convergence/CURRENT-STATUS.md`
- `research/product_ontology/`
- the received GPT Pro convergence delta, its deterministic intake audit, and the current
  686-quotient rebase that keeps all candidate decisions unratified;
- `research/domain_atlas/universes/`
- the consolidated 1,037-expert and 83-specialist-company navigation indexes;
- `research/domain_atlas/compiler/library_registry/contract_generation/semantic_decomposition/`
- the root machine-readable files under
  `research/domain_atlas/compiler/library_registry/` needed to resolve libraries, operations,
  requirements, offers, dependencies, evidence, crosswalks, gaps and the combined registry.

Excluded:

- application/runtime source code unrelated to this research;
- Git metadata;
- caches, bytecode and platform metadata;
- previous GPT handoff ZIPs;
- any claim that the packaged checkpoint is canonical, implemented or complete.

The ZIP is an evidence-bearing research input. Paths inside the archive retain their repository
locations so returned deltas can reference exact input artifacts.
