# Document and text processing semantic slice

This package is an evidence-backed, owner-unratified decomposition of the exact libraries reached
by `product.document_processing_review` plus the currently unconsumed shared text-semantics
foundation. Declared product bindings—not library-name matching—define the universe.

## Boundary result

- The current product has 27 concrete dependencies: 13 document-native libraries and 14 shared
  imports owned by case, decision, identity, provenance, validation, export, representation or
  materialization contexts.
- `library.method_kernels.text_semantics` is a missing shared foundation candidate for decoding,
  normalization, segmentation, collation and source-offset mapping; it is not a new product.
- Search/index and annotation operations remain neighboring products. Document processing supplies
  versioned content, candidates, selectors and evidence through published-language seams.
- Parser and model providers remain anti-corruption adapters or method implementations, never
  semantic owners.
- Document-specific provenance owns only transformation and anchor loss. Generic provenance remains
  in the lineage/provenance bounded context.
- Review records an authority-bound judgment; it does not manufacture reviewer authority or turn
  an extraction into accepted business truth.
- Ten declared product imports have no P5/coordinate docket under their concrete library ID. This
  routing defect is encoded as a typed vacancy and keeps compiler binding refused.

The slice contains 40 primary, normative or official sources, 38 semantic modules, 63 method
boundaries, 47 non-collapse laws, 16 expert-learning profiles, ten recent non-LLM innovations, 28
exact library bindings and 448 explicit library-by-axis questions. It selects no coordinate answer,
owner decision, exact contract, provider qualification or canonical closure.
