# Semantic-role coordinate ontology

This package answers **what role does an exact subject occupy in one exact interaction?** A role is
positioned by operation, counterparty, direction, port, authority, effect and responsibility. It is
not the subject's intrinsic kind or a permanent noun.

Forty-six role archetypes and fifty-four operation kernels distinguish value/predicate/transform,
planner/compiler/optimizer, required/provided port, inbound/outbound adapter, provider/runtime,
repository/ledger/projection, controller/coordinator, oracle/instrumentation, semantic/implementation
owner and producer/consumer positions. All 674 members are routed losslessly. The ten primary
sources constrain bounded distinctions; the 23 family dockets bind no applicability evidence and
make no role, owner, authority, effect, provider or contract decision.

Run `python3 build_semantic_role_coordinate_ontology.py` and `python3 validate.py`.
