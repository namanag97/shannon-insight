# Cross-axis coordinate audit

Per-package validation is necessary but insufficient. This audit joins all sixteen coordinate
packages back to the 10,784 exact member-axis cells and 368 family-axis quotients, checks whether
each axis exposes a normalized compiler coordinate/outcome/refusal surface, and records twenty
non-collapse seams that require contradiction tests before ratification.

The audit first exposed that the six original targeted coordinate campaigns routed only selected
occurrences: 9,545 primary routes left 1,239 cells uncovered. `coordinate_route_completion/` now
adds explicit structural evidence-vacancy routes for those cells, so all 10,784 cells are scheduled
without pretending that evidence or coordinate answers were supplied. Ten axes have full primary
routing; six reach full routing through the conservative completion layer.

`coordinate_compiler_ir_normalization/` additionally projects the nine axis-native surfaces into
the common coordinate-field, total-outcome and compiler-refusal contract used natively by the other
seven. All sixteen are now structurally inspectable through one IR surface; exact refusal
precedence and every semantic decision remain open.

Run `python3 build_cross_axis_coordinate_audit.py` and `python3 validate.py`.
