# P3C composition/algebra coordinate ontology

This package refines the flat `composition_algebra` axis into decisions attached to exact
operators, operand/result positions and use sites. It distinguishes carriers, arity, laws,
partiality, precedence, evaluation order, information loss, effects, authority, resources and
proof obligations. A word such as `merge`, `combine` or `compose` is never itself an operator
contract.

The package preserves every targeted member through a reversible route and groups members only by
exact family, preclassification and ordered lexical-facet signature. Those clusters are research
mechanics, not semantic equivalence classes. Lexical facets remain discovery-only; they do not
supply operator inventories, coordinate profiles, applicability, ownership, exact contracts or
gap closure.

Build and validate with:

```bash
python3 build_composition_algebra_coordinate_ontology.py
python3 validate.py
```
