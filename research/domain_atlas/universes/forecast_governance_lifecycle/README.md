# Forecast Governance and Lifecycle

This candidate universe closes forecast-specific selection, definition/edition, override and publication-profile semantics while importing generic adjudication and data-product publication mechanics.

```text
selection profile -> evidence appraisal -> external authority judgment
definition compiler -> edition/run/artifact lifecycle
override policy -> override lifecycle -> ex-post value evaluation
publication profile -> generic publication/change/recall protocols
```

Score is not selection. Recommendation is not approval. Definition is not run. Base is not override. Positive forecast value added is not causal proof. Approval is not publication; publication is not consumption; recall issuance is not completed propagation. No implementation is qualified or portable.
