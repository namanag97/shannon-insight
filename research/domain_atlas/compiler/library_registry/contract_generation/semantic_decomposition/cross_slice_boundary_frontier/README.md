# Cross-slice boundary frontier

This package converts the boundary findings emitted by every live analytical-formalism semantic
slice into a lossless adjudication graph. It does **not** declare 205 new canonical libraries.
It preserves 205 exact proposed seams and 116 other product/capability decisions, then groups them
only by reusable review mechanics.

The key distinction is:

```text
same review archetype
        != same meaning
        != same owner
        != interchangeable type
        != merge permission
        != ratified library
```

Every proposed seam retains its exact identity and source finding. Its primary semantic quotient
selects a review package; secondary quotients expose cross-cutting mechanics. A mandatory local
residual preserves domain vocabulary, applicability, invariants, API, owner and acceptance tests.
Each seam also receives an owner-candidate docket grounded in its source slice's semantic modules.
The docket tests a local context, existing-context imports and a shared-mechanic context as
counterfactuals; none is selected merely from the namespace or surface name.

The ratification path is deliberately refusing:

```text
exact findings
    |
    v
semantic review quotients -- no merge claim
    |
    v
cross-namespace collision tests
    |
    v
owner candidates
    |
    v
product boundary decisions
    |
    v
library boundary decisions
    |
    v
exact contract lowering
    |
    v
two implementation qualifications
    |
    v
unrelated vertical acceptance
```

The P0 graph is a candidate replacement graph, not a verdict. In particular it records that a
managed warehouse may consume query semantics without owning them, Embedded Analytics may consume
BI report/presentation contracts while retaining its own entitlement ACL, reconciliation may
consume quality evidence without acquiring quality authority, and reusable method kernels need not
become a product. Each statement remains reversible until owner authority, cohesion evidence,
counterexamples and unrelated-vertical acceptance are present.
