# Phase 5 — behavior, resources and proof

This candidate closes the global semantic-axis design pass. It defines semantic roles and total
operation contracts, explicit composition laws, finite resource/failure semantics, and scoped
evidence/conformance. It prevents type signatures, adapters, retries, telemetry or passing tests
from becoming universal guarantees.

Existing family owners remain sovereign. Families inherit this constitution and record only
applicability and exceptions; implementations remain unqualified until exact source contracts,
profile-specific conformance and production acceptance pass.

Run `python3 build_phase5.py`, then `python3 validate.py`.
