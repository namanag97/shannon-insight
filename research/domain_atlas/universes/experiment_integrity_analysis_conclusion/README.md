# Experiment Integrity, Analysis and Conclusion

This candidate universe closes the Experimentation Platform seams between sealed protocol/assignment/exposure/cut contracts and an externally authorized business decision.

It defines six replaceable contracts:

1. prospective integrity-profile compilation;
2. observed integrity evaluation;
3. experiment-specific analysis binding;
4. immutable analysis-result sealing;
5. evidence-bounded conclusion appraisal; and
6. conclusion publication, correction, retraction, supersession and decision-evidence handoff.

The boundary deliberately refuses these collapses:

```text
integrity finding != diagnosis != pause/stop decision
analysis binding  != estimator implementation
execution success != valid result != reproducibility
estimate           != conclusion != decision != release
publication        != truth
retraction issued  != propagation completed
```

All contracts are specified but unimplemented. Structural matching cannot make an offer qualified, portable or selectable.

Run `python3 build_corpus.py` and `python3 validate_corpus.py` from this directory.
