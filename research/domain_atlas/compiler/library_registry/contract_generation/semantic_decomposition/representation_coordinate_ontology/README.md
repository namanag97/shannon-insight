# Representation coordinate ontology

This package separates bounded-context meaning, published semantic profiles, logical and constraint
schemas, carrier types, physical layouts, buffers, containers, frames, codecs, canonicalization,
wire/API contracts, language/ABI bindings and provider or legacy adapters.

Forty-eight representation bearers and sixty kernels route all 674 exact library members through
lossless family/facet clusters. The 175 lexical candidates remain discovery signals only; the other
499 members require a complete representation inventory. No route decides applicability, ownership,
preservation, loss, an exact contract, implementation fitness or canonical gap closure.

The main law is directional: a representation binding names source and target editions, direction,
profile and preservation obligations. Matching fields, successful parsing, unknown-field retention,
round-trip bytes, zero-copy layout, canonical bytes or a provider binding cannot prove semantic
equivalence.

Run `python3 build_representation_coordinate_ontology.py` and `python3 validate.py`.
