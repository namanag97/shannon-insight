# Library coordinate binding projection

Every exact library now has sixteen compiler-coordinate requirements linked to its primary or
supplemental route, normalized axis profile, family-axis factorization and P5 exact-contract docket.
Each library docket also imports all twenty seam obligations and their structural negative-test
receipts.

All 674 compiler bindings refuse because coordinate answers, refusal precedence, applicability,
owner decisions, semantic seam appraisals and exact contracts remain unresolved. This package makes
the future compiler's missing inputs explicit; it does not satisfy them.

Run `python3 build_library_coordinate_binding_projection.py` and `python3 validate.py`.
