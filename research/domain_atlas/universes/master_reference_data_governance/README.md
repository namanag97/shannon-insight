# Master and Reference Data Governance

This universe closes seven compiler-critical boundaries without collapsing entity resolution, source records, master identity, survivorship projections, reference values, codes or mappings.

```text
Master Data                             Reference Data
├── domain identity                     ├── reference-set editions
├── source attribute authority          ├── code-set lifecycle
├── survivorship projection             └── crosswalk mappings
└── stewardship cases
```

Critical laws:

```text
source record != match score != resolution assertion != master identity
master identity != survivorship projection != source truth
latest != most complete != most authoritative
steward decision != source correction effect
reference value != mastered business entity
code != concept != designation != display label
crosswalk relation != equivalence
forward mapping != reverse mapping != round-trip preservation
```

Identity issuance, stewardship actions, reference publication and code/mapping lifecycle operations emit pure effect intents. They require external authority and receipts. All reference offers remain unqualified, non-portable and non-selectable.
