# Semantic-object coordinate ontology

This package answers **what exact kind of thing is governed at each library/use-site position?**
It prevents a universal `Object`, record, JSON document or Rust struct from collapsing referent,
identifier, representation, type, instance, occurrence, entity, event, fact, observation, command,
intent, plan, rule, policy, decision, state, snapshot, relation, graph, resource, capability,
entitlement, allocation, execution, effect, claim, evidence and proof.

The ontology defines 33 subject/bearer archetypes, 55 operation kernels and the coordinates needed
to bind them inside an exact bounded context, owner, metalevel, edition and use site. All 674 live
semantic-object members are routed losslessly through mechanically derived research clusters.

The eight primary sources constrain bounded distinctions only. The 23 family dockets are structural
projections of the authoritative preclassification corpus and deliberately contain no family
source-evidence binding. No kind, role, applicability, owner, contract or canonical closure is
claimed.

Run:

```text
python3 build_semantic_object_coordinate_ontology.py
python3 validate.py
```
