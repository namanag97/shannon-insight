# Quality, reconciliation and controls semantic slice

This unratified research package decomposes two related but sovereign products without restoring
the former combined “quality and reconciliation” boundary.

```text
purpose + consumer + risk
          |
          v
quality requirement --> dimension + metric + rule + policy
          |                         |
          |                         +--> declared contract/schema ACL
          v
exact subject + population + data cut + evaluation configuration
          |
          +--> validation/profile/sample --> measurement + total outcome
          +--> baseline/anomaly/shift/change --> quality signal
          +--> telemetry/lineage correlation --> alert/case
                                                   |
                                            authorized defect verdict

                                      quarantine / waiver / repair proposal
                                                   |
                                      explicit approval + effect port
                                                   |
                                      correction/restatement + retest

reconciliation definition
  = comparison populations + truth roles + keys/transforms
  + exact/tolerant/aggregate match + materiality + residual law
          |
          v
reconciliation run --> matched set + break set --> investigation/disposition
                                                    |
                                      bounded control-completion receipt

assertion outcome != enforcement disposition
signal != defect; discrepancy != break; break != defect
repair proposal != approved correction != source observation
certificate != measurement truth != universal fitness
```

The product split is preserved:

```text
Data Quality Operations
  owns purpose-scoped requirements, rules, evaluations, measurements, signals,
  quality cases, defect adjudication, quarantine, waiver, remediation and scoped certification

Reconciliation & Control Operations
  owns comparison populations, truth roles, matching/tolerance, runs, breaks,
  materiality, dispositions and bounded control completion

Imported owners
  data contracts + schema editions + master/reference identity + entity merge/split
  statistics + quantities + lineage + telemetry + notification delivery + decision/effect ports

Vertical profile
  accounting/control reconciliation vocabulary and authority
```

reference/master alignment, duplicate/entity resolution and accounting-control reconciliation.

methods, 20 expert learning profiles, 26 recent non-LLM innovation records, 72 library bindings,

contract, provider, implementation or product readiness. All compiler bindings remain refused.
