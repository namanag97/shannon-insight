# Graph, network, ontology and knowledge semantic slice

This unratified research package rejects the common collapse of every graph-shaped concern into a
single “knowledge graph” product.

```text
source entities/relations/events
          |
          v
loss-bearing graph projection + semantic profile
          |
          +--> logical graph occurrence/snapshot/view
          |        +--> node/edge identity, direction, multiplicity, properties, weights, time
          |        +--> property graph / RDF dataset / hypergraph / multiplex profile
          |
          +--> algorithm plan
          |        +--> traversal / paths / connectivity
          |        +--> centrality / communities / cuts / flows / cores
          |        +--> matching / motifs / isomorphism / similarity / link scores
          |        +--> sampling / temporal analysis
          |        +--> semiring kernels + explicit backend/budget
          |                    |
          |                    +--> typed result + witness + evidence receipt
          |
          +--> ontology edition + import closure
                   +--> axiom/logic profile
                   +--> reasoning / entailment / consistency / classification
                   +--> shape validation / mapping
                   +--> assertion status + governed knowledge release

graph carrier != logical graph != projection != snapshot != algorithm plan != result
path/reachability != causality or authorization
centrality != importance/truth; community != real-world group
entailment != observed truth; SHACL conformance != ontology consistency
knowledge-graph release != graph database/query engine/analytics workbench
```

The product-boundary result is explicit:

```text
Ontology / Knowledge-Model Governance        retained product
  ontology identity/imports
  axiom profiles
  reasoning/entailment
  shape validation
  ontology mappings
  governed knowledge-graph releases

Graph Analysis Workbench                     retained separate boundary; unratified
  graph projection/profile
  workspace and run lifecycle
  traversal/path/centrality/community/etc.
  result comparison, evidence, review and publication
  imports exact method libraries; does not own their semantics
  excludes the legacy graph-method facade

Imported sovereign seams
  graph query and storage
  predictive graph models/message passing
  causal/process/spatial/document/trace/vertical graph semantics
  visualization and business decision/effect authority
```

The package binds the exact 11-library union of the ontology and graph-workbench products plus 23 justified graph-method,
query/storage, predictive, provenance, specialized-graph and presentation neighbors. It contains
27 primary or official sources, 49 semantic modules, 36 non-collapse laws, 108 method types, 20
expert learning profiles, 10 recent non-LLM innovations, 34 library bindings, 544 unresolved
library-axis questions, no missing-product candidate, 11 missing-library candidates and 19
boundary findings. Ten libraries lack complete P5 plus coordinate routes.

No source or structural match ratifies the retained Graph Analysis Workbench boundary, an owner,
member applicability, coordinate value, exact contract, provider, implementation or product
readiness. All compiler bindings remain refused.
