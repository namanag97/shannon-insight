# Time coordinate ontology

This package replaces library-wide `timestamp` assumptions with temporal decisions attached to
exact bearers and use sites. It separates instants, local/offset/zoned date-times, civil dates,
elapsed durations, calendar periods, intervals, occurrence/observation/validity/recording/
processing/decision/effect/correction roles, schedules, deadlines, TTLs, windows, watermarks,
logical clocks, bitemporal facts and as-of snapshots.

All 674 time-axis members are routed from the authoritative all-axis preclassifications. Unlike
the six evidence-campaign rebases, the 23 family dockets here are explicitly structural: no family
source-evidence binding is fabricated. Primary standards constrain reusable coordinates and
negative laws only; family applicability, member profiles, owners, exact contracts and closure
remain open.

Build and validate with:

```bash
python3 build_time_coordinate_ontology.py
python3 validate.py
```
