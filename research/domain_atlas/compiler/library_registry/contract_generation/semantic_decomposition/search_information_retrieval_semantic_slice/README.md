# Search, information retrieval and metadata-discovery semantic slice

This deterministic, evidence-backed and unratified slice decomposes the final open analytical
formalism quotient. It retains Search & Index Serving and Metadata Discovery as independently
adoptable products joined by an explicit projection/index ACL.

## Boundary result

```text
sources → acquisition → metadata assertions/conflicts → discovery projection
                                                        │
                                                        └─ publish to search index

content occurrences → mutation generation → visibility cut
                                             │
query → lexical/structured/spatial/vector/hybrid retrieval → ranking → result/evidence
```

- Search & Index Serving owns index schemas/analyzers, mutation generations, searchable visibility
  cuts, retrieval plans, ranking profiles, results, relevance evidence, deletion and rebuild.
- Metadata Discovery owns source acquisition, metadata assertions/conflicts, resource/record
  projections, vocabulary mapping, federation, browse navigation, freshness and coverage evidence.
- A search index document is a serving representation, not a metadata assertion or catalog truth.
- Vector/ANN retrieval is one typed method family beside lexical, structured, spatial and hybrid
  retrieval—not an ambient AI product or feature-platform responsibility.
- Embedding and ranking model training, approval, monitoring and retirement remain in the external
  model lifecycle; search binds exact editions only.
- Exact database query, graph query, ranked retrieval, browse navigation and discovery query are
  typed homonyms with different algebra, order and completeness semantics.
