# Bulk contract-generation program

This program replaces manual one-by-one exact-API drafting with a governed three-level model:

```text
contract archetype          structural obligations only
        +
family constitution        owner-authored shared semantics and evidence
        +
library instance           owner-authored differences and exceptions
        =
source contract candidate  eligible for canonical normalization and validation
```

The generated files are planning and obligation artifacts, not semantic authority. They cannot
close an exact-API gap. A gap closes only after boundary adjudication and publication of an exact
contract by the source universe's named semantic owner.

The program emits 19 structural archetypes, one constitution work item per research family, one
instance proposal per open exact-API gap, complete owner-scoped boundary-falsification clusters,
146 cross-owner lexical collision signals, and one executable work package per family/lane research
batch. Collision signals are discovery aids rather than duplicate or merge proof. Classification is explicitly either
mechanical-high-confidence or heuristic-review-required. Neither state is acceptance.

The 57 work packages are arranged into seven dependency waves: boundary/data-shape adjudication;
shared foundations and representation; the connector/messaging/storage/pipeline/query/runtime
execution spine; assurance and control; analytical methods; consumption and commercial support;
and finally removable model/agent extensions. Wave order is a dependency strategy, not a claim that
all contexts inside a wave share semantics.

Run from the repository root:

```sh
python3 research/domain_atlas/compiler/library_registry/contract_generation/build_program.py
python3 research/domain_atlas/compiler/library_registry/contract_generation/validate.py
```

The execution order is boundary first: falsify, merge, split, narrow or retire candidates; complete
and freeze an editioned family constitution; bind bounded primary-evidence claims; fill each
library's semantic slots; expand structural obligations; run collision, dependency and unrelated-
vertical tests; publish source contracts; regenerate the canonical registry; and verify that only
the intended exact gaps disappeared.

Generated names, inferred defaults, vendor surfaces, package layouts and model/agent proposals are
never accepted as domain meaning, authority or implementation qualification.

The first pilot under `pilots/lineage_provenance_evidence/` extracts an owner-reviewable family
constitution from that universe's existing metamodel and evidence model. Across 31 still-open
library instances it factors 329 repeated review units into 12 shared family slots plus eight local
slots and one per-library applicability attestation. This is measured review compression, not
semantic acceptance: all applicability attestations and all 31 canonical exact gaps remain open.

Wave 0 under `wave0_data_shape_boundaries/` applies the same principle before API generation. It
adjudicates all 33 provisional data-shape library boundaries against one five-layer constitution,
retains 23 representation mappings as independent bindings, and groups the 33 traceable decisions
into five semantic-kind ratification packages. Thirty-two mixed boundaries require split/rename;
glTF is treated as a scene-graph representation profile rather than a new universal logical shape.
The bundle is root-gated but performs no silent canonical mutation and closes no exact-API gap.

The complementary `semantic_decomposition/` program gives every open library a complete vector
across 16 orthogonal axes and 109 reusable facet modules. Structural archetype and semantic vector
are deliberately independent: an effect port and a pure algebra may both carry bitemporal or
partial-order meaning, while two runtimes may have completely different authority and uncertainty
laws. All 674 gaps are covered through 368 family-by-axis review packages. Lexical matches are
discovery candidates, missing matches remain unresolved, and neither state is domain authority.
Every facet also has an anti-explosion realization disposition: 63 currently reference an existing
foundation or archetype, while the remainder stay domain/family constitution slots or explicit
profiles instead of becoming new libraries. Six bounded primary-source claims anchor the first
identity, time, authority, telemetry, schema and physical-layout seams. Execution is organized as
16 axis lanes in five dependency phases, not as 368 serial specifications.
