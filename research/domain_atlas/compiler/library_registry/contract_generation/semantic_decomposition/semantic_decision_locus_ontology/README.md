# Semantic decision-locus ontology

This package answers the question that a flat semantic matrix cannot: **what
does an axis decision attach to?** A whole-library label is usually too coarse.
Time may attach to a fact, transition, interval or observation; authority may
attach to an assertion, decision, delegation, effect or acceptance; failure may
attach to a port, execution attempt, partial effect or recovery obligation.

Ten bearer archetypes cover subjects, relations, operation positions,
transitions/histories, authority/policy, representations, execution
obligations, evidence claims, compatibility paths and composition expressions.
Sixteen axis profiles declare their valid bearers, coordinate questions,
dependencies and conditions that force a local residual.

The 10,784 existing member-axis cells remain exact. They are initially factored
through 368 family-axis quotients, giving a reusable decision point without
copying a family default into 674 members. Each quotient must still produce
member exception clusters and operation/port/use-site residuals where the axis
profile requires them.

The central propagation rule is strict: reuse is allowed only when the bearer
coordinate, dependencies, invariants, authority, effect and evidence profile
match exactly. Otherwise the compiler sees an explicit qualification, lossy
mapping or local residual.

No family default, member applicability, owner, exact contract or gap closure
is asserted by this package.

Detailed coordinate refinements are currently linked for semantic object, semantic role,
authority/trust, effect boundary, evidence/conformance, identity/equality,
grain/cardinality, state/change, order/topology, composition/algebra, partiality/uncertainty and
time, representation, compatibility/evolution, privacy/security/safety and resources/failure.
Together they preserve 9,545 exact member routes. All sixteen locus profiles now have structural
bearer-specific coordinate ontologies; this is routing completeness, not semantic or contract
completion.
