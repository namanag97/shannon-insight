# Phase 2 — dynamics and information

This evidence-backed candidate defines four reusable semantic constitutions:

```text
state/change × time × order/topology × partiality/uncertainty
```

It separates commands, events, histories, state and snapshots; eleven application time roles;
total, partial, causal, arrival and partition order; thirteen information states; and nine
uncertainty coordinates. It projects compiler roles, adapter proofs and typed refusals while
prohibiting universal State, Event, Timestamp, Order, Null and Uncertainty facades.

Seven bounded primary claims use W3C SCXML, Lamport's clock/order paper, OWL-Time, Apache Beam,
Apache Arrow, XACML and OpenTelemetry Metrics. The package remains pending named-owner ratification
and closes no canonical exact contract.
