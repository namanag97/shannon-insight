# Semantic gap topology

> **Live-count authority:** Numeric snapshots in the narrative below are historical context.
> `summary.json` is authoritative for the current cluster/atom frontier, and
> `frontier_accounting/summary.json` plus its validator prove exact cluster-to-atom-to-kernel
> routing. Neither file claims semantic closure, implementation, qualification or acceptance.

This control plane classifies open work orthogonally by defect, semantic axis, locus, grain, epistemic state, closure operation, authority, evidence, dependency role, blast radius and lifecycle.

The 685 exact clusters are also factored losslessly into **10 closure-method kernels**. A method
kernel means the question protocol, evidence/receipt schema, validator generator and negative-test
pattern can be built once. It does not mean the semantic answer, owner, applicability, provider
verdict or product acceptance can be shared. `closure-method-kernels.jsonl` contains every cluster
exactly once and still represents all 16,658 open atoms.

The important unit of execution is a root-cause cluster, not an individual library checkbox. Family-axis research and ownership decisions are performed once, propagated to all members, and followed by review of only the residual exceptions. Structural validation, evidence, authority, specification, implementation, qualification and product acceptance remain separate gates.

The cluster list is an attribution ledger, not a serial task list. `macro-execution-bands.jsonl`
schedules every cluster exactly once into ten dependency bands. Within a band, named symbol waves,
semantic-axis lanes, families, contract archetypes and qualification gates are parallel lanes. This
keeps all residuals attributable while avoiding a 674-library or 814-product-vacancy checklist.

`closure-lattice.json` defines the reusable layers: source concept scheme, global constitution,
shared primitive, contract archetype, family profile, exact library instance, implementation offer,
product assembly and vertical solution pack. Decisions are made at the highest valid layer and
inherited by exact digest. Lower layers may only specialize through explicit evidence-backed
profiles; products may compose imported libraries but cannot absorb their semantic ownership.

The semantic-axis tensor remains orthogonal to the method quotient. Two clusters can reuse a method
while reaching different semantic conclusions; two semantically adjacent clusters can require
different authorities or evidence and therefore remain in different method kernels.
