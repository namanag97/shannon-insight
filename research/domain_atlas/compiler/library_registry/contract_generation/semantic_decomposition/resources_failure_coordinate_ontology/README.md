# Resources/failure coordinate ontology

Finite resources and failures attach to exact operation attempts, runtimes, topologies, policies and
acceptance profiles. Demand, offer, availability, reservation, allocation, quota, budget and usage
are distinct; so are deadline, timeout, cancellation request, observed cessation and termination.

Fifty-five bearers and eighty kernels route all 674 members through exact clusters. Retry is a new
budgeted attempt; transient labels do not prove safety; provider strings do not become domain
errors; partial and unknown completion are total outcomes; degraded operation and recovery require
authority, residual ownership and evidence. All semantic and exact-contract decisions remain open.

Run `python3 build_resources_failure_coordinate_ontology.py` and `python3 validate.py`.
