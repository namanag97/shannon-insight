# Semantic-axis decomposition

Structural archetypes answer what kind of contract machinery is needed. Semantic axes answer what
meaning that machinery must preserve. These are independent decompositions:

```text
library boundary
  ├─ structural archetype: algebra / policy / compiler / port / runtime / adapter ...
  └─ semantic vector:
       object × role × identity × grain × state/change × time × order/topology
       × partiality/uncertainty × authority × effect × representation × composition
       × compatibility × resources/failure × evidence × privacy/security/safety
```

The generator emits one complete 16-axis discovery signature for every open exact-contract gap.
Ninety-plus reusable facet modules supply constitutional questions and non-collapse laws. Pattern
matches are explicitly lexical discovery only; missing matches remain unresolved and are never
treated as inapplicable. The effect boundary is copied from an explicit source field but still
requires owner ratification with the complete vector.

Discovery intentionally excludes generic laws, refusal templates, conformance boilerplate and
evidence references. Only declared names/responsibilities and concrete public operation/type
vocabulary can trigger a lexical candidate. This prevents repeated constitutional text from
creating false semantic coverage.

Review happens as family × axis packages. Owners ratify a shared module once, then record
applicability and exceptions per library. This reduces repeated reasoning while retaining every
library's separate identity, evidence, refusal surface and exact source-contract gate.

`facet-realizations.jsonl` prevents ontology-to-library explosion. Every facet is explicitly
resolved as an import of an existing foundation, a composition of foundations, a structural
archetype, a domain overlay/profile, or a domain-constitution slot that is not independently a
library. Even mapped facets remain candidates until their owners ratify exact semantic identity,
edition, laws and guarantees.

`foundation-evidence-claims.jsonl` records bounded primary-source claims and explicit authority
limits. It currently anchors URI comparison, temporal carriers, policy decision/enforcement,
telemetry observation, schema assertion and columnar physical-layout distinctions. Evidence can
support a seam without becoming the owner of every domain meaning that crosses it.

`semantic-research-queue.jsonl` ranks all family-axis packages using exact-gap priority, retained
product/vertical use, unresolved-member count and horizontal axis leverage. Ranking changes research
order only; it neither converts lexical candidates into truth nor permits a high-ranked family to
override another owner.

The ranked queue is not executed serially. `semantic-axis-lanes.jsonl` collapses it into 16 global
axis lanes, each with 23 independently reviewable family matrices. Five dependency phases establish
subject/grain first; then dynamics/information; authority/effects/safety;
representation/evolution; and finally behavior/resources/proof. Global axis constitutions are
frozen once, family matrices proceed in parallel, and libraries store only exceptions.
