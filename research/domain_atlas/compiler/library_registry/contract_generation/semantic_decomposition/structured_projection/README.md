# Global structured semantic projection

Every one of the 674 open library gaps has a matching rich `library_contribution` record containing
typed API, behavior, effects, boundaries, finite bounds, evolution, execution, conformance,
evidence, dependencies, replacement seams and upstream source provenance.

This layer projects those records across all sixteen semantic axes and emits a rich exact-contract
input candidate per library. It supersedes lexical discovery for research routing, but not for
authority: every upstream source projection explicitly says its schema is non-canonical. Therefore
the generated names and contracts remain candidates until boundary owners adjudicate semantics,
signatures, laws, refusals, defaults, evidence and conformance.

Evidence has four states: direct structured candidate, targeted structured candidate, generic
context that still leaves an axis vacancy, and complete vacancy. Term matching never establishes
applicability. The corpus makes blank-slate API invention unnecessary without pretending the
existing generated/source-projected API is correct.

Only generic structural context exists for 2,805 rows. These occur on six axes and are grouped into
103 family-axis packets in `targeted-evidence-work-packages.jsonl`. Each packet includes the exact
members, archetype distribution, existing context fields, one sovereign research question and the
required evidence, decision, collision, exception and negative-twin outputs.

The 674 inputs originate in exactly 23 upstream files, so source schema/record authority is grouped
into 23 parallel packages in `source-authority-work-packages.jsonl`. `execution-dag.json` then
connects constitution ratification, source authority, three targeted-evidence phases, family
applicability, exact contracts, implementation conformance and unrelated-vertical acceptance.

Run `python3 build_projection.py`, then `python3 validate.py`.
