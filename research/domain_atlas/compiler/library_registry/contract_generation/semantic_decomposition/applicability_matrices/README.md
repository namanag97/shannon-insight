# Semantic applicability matrices

This layer converts the 16-axis discovery corpus into owner-ready work without inventing semantic
decisions. It has three levels:

1. A family-axis matrix points to the global constitution and asks for one family default.
2. Candidate clusters group members with identical mechanical discovery signals.
3. Member rows retain every library as an independently accountable exception target.

No signal means unresolved, never inapplicable. Lexical and explicit-source signals are candidates,
never applicability decisions. Even the unique modal cluster is only a presentation/defaulting
candidate until a named owner supplies bounded evidence and ratifies it using
`owner-decision.schema.json`.

The generated corpus covers 10,784 library-axis cells exactly once through 368 family matrices.
It reduces repeated authoring, not semantic accountability. No exact library gap closes here.

Run `python3 build_matrices.py`, then `python3 validate.py`.
