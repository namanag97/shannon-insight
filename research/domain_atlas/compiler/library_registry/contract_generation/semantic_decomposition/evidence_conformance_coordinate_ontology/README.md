# Evidence and conformance coordinate ontology

This package models proof as a scoped tensor over claim, subject edition, profile, evidence method,
inputs, environment, coverage, time, provenance, independence, defeaters, verdict and acceptance
authority. It prevents provenance, signatures, examples, test passes, TCK results, fuzzing, model
checking, formal proofs, telemetry, benchmarks or attestations from becoming global proof flags.

Forty-four proof bearers and fifty-nine kernels route all 674 members exactly. The 583 members with
no evidence-oriented lexical signal remain explicit oracle/evidence vacancies. All 23 family
dockets make zero evidence, conformance, qualification or acceptance decisions.

Run `python3 build_evidence_conformance_coordinate_ontology.py` and `python3 validate.py`.
