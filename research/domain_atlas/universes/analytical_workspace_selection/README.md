# Analytical Workspace and Selection

This generated open-world corpus separates the governed analytical-work aggregate from tenant
collaboration workspaces, UI-layout workspaces and runtime sessions. It also separates predicate
language/type semantics, reversible selection state and facet evaluation.

No source, structural mapping or reference offer qualifies an implementation. Regenerate with
`python3 build_corpus.py` and validate with `python3 validate_corpus.py`.
