1. Charter and ownership

1.1 Positive charter

Identifier owns the semantics required to admit and use a typed token: kind binding, construction mode, explicit construction material, identifier scope, uniqueness basis, immutable representation definition, canonical and accepted forms, declared ordering, interaction/disclosure posture, reuse qualification, IdentifierIssuanceWitness and profile evolution. It supplies both statically typed and declaration-selected dynamic use through one semantic implementation.

1.4 Owned shapes

The family owns Value, Decision, State machine (Series only), semantic data cards and typed contract seams. It owns no generic compiler, linker, registry, host, adapter, runtime loop, store, ledger, target IR or process envelope. There is no family-native plan: admission produces native admitted definitions; application closure belongs to the shared linker.
