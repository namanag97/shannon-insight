# Human Work, Review, Agreement, Consensus and Adjudication

This generated open-world corpus separates task definition and assignment, evidence-anchored review
issues, agreement/reliability measurement, consensus rule compilation/evaluation, and authority-
scoped adjudication. Product-specific work meaning and acceptance remain outside.

No structural record qualifies an implementation. Run `python3 build_corpus.py` and then
`python3 validate_corpus.py`.
