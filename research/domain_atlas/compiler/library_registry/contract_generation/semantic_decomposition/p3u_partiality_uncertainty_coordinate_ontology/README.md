# P3U partiality/uncertainty coordinate ontology

This package prevents null, absence, unknown, invalidity, staleness, pending work, partial effects,
censoring, redaction, incompleteness, approximation, intervals and probability distributions from
collapsing into one optional value. Decisions attach to exact bearer positions, populations,
temporal scopes, uncertainty-profile editions and use sites.

The coordinate records missingness mechanism, completeness, horizon/freshness, units/support,
coverage/calibration, assumptions/dependence, propagation, aggregation, imputation, thresholds,
authority/disclosure, resources and conformance. Every target member is routed exactly, while
lexical facets remain discovery-only and supply no applicability, owner, exact contract or closure.

Build and validate with:

```bash
python3 build_partiality_uncertainty_coordinate_ontology.py
python3 validate.py
```
