# Specialized Geospatial Workbench

This candidate universe decomposes eight coarse Geospatial Workbench gaps into eighteen exact project, layer, workflow, geocoding, routing, trajectory, terrain/hydrology, point-cloud/3D, accuracy-appraisal and publication-profile contracts.

It imports generic storage/query, graph algorithms, provenance, adjudication and data-product publication/change/recall mechanics. Representation is not territory; match is not identity; proximity is not reachability; map match is not observed movement; conditioned terrain is not source truth; classification is not physical-object identity; publication is not authority; map is not action.

All profiles are unexecuted. No implementation, provider, result or product is qualified or portable.
