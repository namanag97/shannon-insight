# P3I identity/equality coordinate ontology

This package separates the identity of a subject occurrence from the many relations commonly
called equality: identifier equality, term equality, typed value equality, structural equality,
canonical representation equality, digest equality, semantic or behavioral equivalence,
approximate matching, graph isomorphism and adjudicated entity identity.

The coordinate binds every decision to an exact subject, relation edition, namespace, lifecycle
scope and use site. It records allocation/reuse, resolution, law profile, missingness, versioning,
alias/merge/split, canonicalization/digest, authority/privacy and conformance obligations. Every
targeted member is routed losslessly, but lexical identifier signals supply no applicability,
ownership, exact contract or closure.

Build and validate with:

```bash
python3 build_identity_equality_coordinate_ontology.py
python3 validate.py
```
