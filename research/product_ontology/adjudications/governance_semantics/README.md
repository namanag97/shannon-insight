# Governance and semantic product-boundary adjudication

Status: evidence-backed adjudicated candidate, not ratified products or qualified providers.

The overloaded word `catalog` is rejected as a semantic owner. The slice distinguishes:

```text
table catalog + commit authority                 (neighbor; lakehouse slice)
metadata discovery projection                    (search / browse / freshness)
business glossary                                (human language and stewardship)
ontology and knowledge model                     (formal axioms / inference / shapes)
schema registry                                  (subjects / versions / compatibility)
data contract registry                           (provider-consumer promises / acceptance)
master and reference data                        (identity / survivorship / codes)
lineage and provenance                           (derivation evidence)
data-quality operations                          (purpose-scoped requirements / validation / defects)
reconciliation and control operations            (populations / truth roles / breaks / completion)
data-use policy                                  (decision / obligations; not enforcement)
data-product publication                         (edition / contract / lifecycle / recall)
marketplace                                      (listing / eligibility / handoff)
```

Models and agents are optional, typed modalities. They may propose classifications, mappings,
matches, rules, tests or remediation. Deterministic owners validate every proposal; models never
gain semantic, policy, master-identity, publication or effect authority. Removing the optional
provider leaves a valid core path or an explicit capability gap.

alias. The two replacements each have a full 29-field DDD dossier. Thirty-three selected QOR
library seams have exact structural compiler maps; all remain unqualified. Data-contract,
master/reference and entity-resolution meanings remain imported, accounting/control vocabulary
remains a vertical specialization, and correction execution remains behind external authority.
