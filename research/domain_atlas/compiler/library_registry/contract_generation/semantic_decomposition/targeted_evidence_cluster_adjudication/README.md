# Targeted Evidence Cluster Adjudication

Six primary-evidence campaigns cover 2,805 library-axis occurrences. Campaign coverage alone does
not decide that a bounded family-level source claim applies to every library or use site.

This package uses the existing coordinate ontologies as a lossless workload quotient:

- 300 coordinate-cluster challenges replace 2,805 unrelated review tasks;
- 199 clusters begin from lexical discovery hypotheses;
- 101 clusters explicitly lack member-level evidence;
- every exact library-axis occurrence remains reversible to its source gap, coordinate route,
  cluster, family evidence candidate and required use-site inventories.

Each cluster must challenge source relevance, inventory the actual semantic bearers/use sites,
execute the negative twin, decide every member, split exceptions and obtain owner ratification.
No cluster conclusion becomes an implicit family default, and no generated record supplies a
coordinate answer or closes a canonical gap.

Rebuild and validate with:

```sh
python3 build_targeted_evidence_cluster_adjudication.py
python3 validate.py
```
