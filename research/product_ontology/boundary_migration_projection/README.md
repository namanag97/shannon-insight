# Product Boundary Migration Projection

This package resolves the arithmetic difference between 72 researched product candidates and 59
retained product boundaries without pretending that every rejected product must map to another
product.

The nine merge candidates and four deferred candidates have 15 explicit adjudication crosswalks.
Their targets include products, capabilities, semantic owners, components, libraries, providers,
patterns, artifacts, suites, standards and neighboring contexts. Two candidates have crosswalks
from more than one adjudication context and therefore receive explicit reconciliation dockets.

The package factors the work into 13 boundary-level work packages while preserving 39 exact
capability-import migrations and the one affected solution-pack product edge. No former product
name remains as a compatibility alias. Every migration refuses until each source responsibility
has one ratified primary owner and the imports/compositions have been rewritten explicitly.

Rebuild and validate with:

```sh
python3 build_boundary_migration_projection.py
python3 validate.py
```
